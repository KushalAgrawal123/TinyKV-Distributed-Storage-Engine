TinyKV — Redis-Inspired Distributed Key-Value Store
Complete Development Plan
Project Vision

TinyKV is a Redis-inspired in-memory key-value database built from scratch in C++ to understand the internal working of modern storage systems.

Instead of using existing databases, the goal is to implement core database and distributed system concepts manually:

TCP networking
custom client-server protocol
memory storage engine
concurrency handling
caching strategies
persistence
replication
sharding
fault tolerance

The project should demonstrate strong understanding of Operating Systems, Computer Networks, Database Systems, and Distributed Systems.
